### ⚡ What I'm Building (Featured Products)

#### 🤖 Nava AI — Open Source Autonomous Agent Platform
* **Why it exists:** Developers need easier ways to orchestrate complex LLM tasks without building custom pipelines from scratch.
* **My Role:** Led the DataPrep sub-team (1 of 4 core teams) at North-Chiang Mai University to engineer data pipelines and agentic workflows. Shipped production-ready code to the open-source repo.
* **Stack:** Python, FastAPI, LLM APIs

#### 🎯 AI Career Intelligence Platform
* **Why it exists:** Generic resume parsers fail to capture the actual context of a developer's skills. This platform uses a deterministic graph to map true skill gaps.
* **What I shipped:** A full-stack pipeline integrating SpaCy with Groq/OpenAI APIs, achieving 94% extraction accuracy, visualized via Neo4j graphs.
* **Stack:** React 19, FastAPI, Neo4j, Redis, Docker, GitHub Actions

#### 🛡️ ShieldRoute — AI Parametric Insurance (Built in 48 Hours)
* **Why it exists:** Gig workers lack instant safety nets. ShieldRoute uses automated triggers (weather, live location) to process claims instantly without human adjusters. 
* **What I shipped:** Architected anomaly detection and integrated live AQI/Weather APIs to build a fully functioning MVP over a weekend. 
* **Stack:** React, FastAPI, MongoDB, Machine Learning

#### ⏳ Talk To Future Me
* **Why it exists:** People need a simple, reliable way to journal for their future selves.
* **What I shipped:** A live web application with **real users** that handles secure authentication and automated, delayed email delivery.
